
# 📱 Nighty on Android (Termux)

Run **Nighty** headless right on your Android
device. No desktop or server needed. Manage
everything from the built-in Web UI.

A Termux-focused fork of
[nighty-linux-headless](https://github.com/glowxx/nighty-linux-headless)
by **glowxx**. It repackages Nighty so it runs
headless, using Wine (plus Box64 on ARM).

## Highlights
- Runs headless: no screen or desktop needed
- Built-in Web UI with your own login
- Browser setup wizard: license, Discord, bot
- Quiet mode by default (no toasts or sounds)

## You’ll need
- Termux on your Android device
- Your own `Nighty.exe` and a valid license
